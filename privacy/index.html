FFrame Launcher

Política de privacidad

Última actualización: 26 de septiembre de 2026

Frame Launcher es un lanzador de aplicaciones para Android. No requiere una cuenta, no muestra publicidad, no integra servicios de analítica y no vende datos personales.

Datos y permisos

  • Ubicación aproximada: si el usuario activa la tarjeta Clima, Frame Launcher obtiene la última ubicación aproximada disponible y envía latitud y longitud a Open-Meteo para recuperar previsión meteorológica y calidad del aire. Frame Launcher no crea ni conserva un historial de ubicaciones. El tratamiento de Open-Meteo se rige por su propia política de privacidad.
  • Calendario: si el usuario concede permiso, la aplicación lee los próximos eventos para mostrarlos en la tarjeta Agenda. Esta información se procesa localmente y no se transmite a servidores de Frame Launcher.
  • Notificaciones: si el usuario concede acceso al listener de notificaciones, la aplicación procesa localmente un resumen para mostrar la tarjeta de Notificaciones. No se transmite a servidores de Frame Launcher y se excluye de las copias de seguridad del sistema.
  • Aplicaciones instaladas y widgets: la aplicación consulta las actividades lanzables y los proveedores de widgets para cumplir su función de launcher. Esa información permanece en el dispositivo.

Conservación y seguridad

Frame Launcher conserva únicamente preferencias locales necesarias para su configuración. No mantiene una base de datos remota de usuarios. Las conexiones meteorológicas se realizan mediante HTTPS y los datos privados de la aplicación no se incluyen en copias de seguridad Android.

Control del usuario

Todos los permisos son opcionales. El usuario puede revocarlos desde los ajustes de Android y puede borrar los datos locales desinstalando la aplicación o desde la pantalla de información de la aplicación.
